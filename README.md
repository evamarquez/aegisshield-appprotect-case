# Case 02 - AegisShield AppProtect

Simulated portfolio case study by Eva Marquez.

This is a separate case from Case 01 - Cybersecurity Platform Modernization. It shows how a project manager could help a fictional cybersecurity company evaluate and plan a new product from the beginning.

## Product

AegisShield AppProtect is a proposed web application firewall service. It would inspect incoming web requests and apply rules that allow, monitor, or block them.

BookEasy is the proposed pilot customer. BookEasy operates an online scheduling application, so the case must balance security with the need to keep login and booking available for legitimate users.

## Current stage

Product definition and technical validation.

The case is still fictional. Customer needs, competitor findings, costs, technical options, and results must be labeled as simulated assumptions or simulated findings.

## What this case will show

- Product discovery and business case work.
- Build, buy, or integrate analysis.
- A limited first release and acceptance criteria.
- A prototype of the administrator experience.
- Product requirements, technical planning, risks, testing, release, and handover.
- A fictional execution record using GitHub or Jira evidence only after the case is defined.

## Boundary with Case 01

Case 01 is the SIEM modernization and BookEasy connector case. This case is a new product initiative. It may consider an event integration with the SIEM, but it does not modify the Case 01 PDF or reuse its project records as if they belonged to AppProtect.
